# Fast Flip! Token Tools

Foundry VTT addon that allows for quick horizontal and vertical mirroring of selected tokens or tiles.

Allows players to flip their own tokens, add an AFK status indicator, raise a hand to ask a question, and pick wildcard token images using easy and configurable shortcuts.

GMs can also use the same set of shortcuts to mirror tiles.

## List of Shortcuts

-   Pressing `G` will mirror the selected tokens and tiles horizontally
-   Pressing `Shift+G` will mirror the selected tokens and tiles vertically
-   Pressing `Shift+K` will toggle the AFK status of any selected tokens
-   Pressing `B` will show a speech bubble with the token's name
-   Pressing `Shift+H` will raise or lower a hand on the selected tokens, with a number showing each token's place in line
-   Pressing `Shift+Alt+H` will lower every raised hand on the scene (GM only)
-   Holding `I` will show a wheel of the selected wildcard token's images; hover one and release to apply it
